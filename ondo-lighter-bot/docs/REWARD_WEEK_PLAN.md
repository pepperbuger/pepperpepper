# 1주 리워드 실험 준비와 판단 근거 (2026-10-30)

최신 요청으로 아래 초기 18bps 관측을 확장한다. 실주문 재개는 금지하며 [5/10/18bps 비교](PAPER_COMPARISON.md)는 새 수집 시작부터 7일을 측정한다. 정확한 새 시각은 로컬 `comparison-launch.json`에 기록한다. 예전 시작·마감·5분 주기 설명은 초기 관측 이력이다. 기존 자료를 삭제하지 않는다. [잔여 포지션 정리](POSITION_CLOSE_PLAN.md)는 별도 승인 대기다.

현재 LIT·ENA 실주문 봇은 정지돼 있다. 공개 관측은 2026-10-30 08:13 KST에 시작했고 2026-11-06 08:13 KST에 종료된다. 첫 관측 성공·오류 0·주문 0을 확인했다. 기록 경로는 이 채팅 작업 폴더의 `outputs/reward-week-20261030/observations.jsonl`과 `.status.json`, 시작 기록 `launch.json`이다. 매일 09:00 예약 점검 `ondo-1`은 중단·중요 변화·종료 시에만 알리고 최종 보고 후 중지한다. PC와 네트워크가 켜져 있어야 관측과 로컬 점검이 진행된다. 공개 호가 관측만 별도 프로세스로 진행하며 주문·서명·인증·자산 변경은 하지 않는다. 기존 `.env`, `config.yaml`, 운영 `data/`는 보존한다. 현재 알고리즘을 그대로 일주일 실운영하는 것은 권하지 않는다.

## 공식 리워드 규칙

[Ondo 공식 공지, 2026-10-27 게시](https://app.ondoperps.xyz/announcements/usdc-rewards-upgrade)를 2026-10-30 KST에 확인했다. 이번 주 유효기간은 10월 27일 00:00 UTC부터 11월 3일 00:00 UTC 직전이다.

- 유동성 대상은 20개이며 각 마켓의 이번 주 풀은 5,000 USDC다. LIT·ENA는 이 목록에 없다. 거래량 보상 대상과 유동성 보상 대상을 혼동하지 않는다.
- 대상: NVDA, TSLA, META, AMD, INTC, MU, SNDK, COIN, MSTR, CRCL, SPCX, US 500, US 100, DRAM, SOXL, Gold, Silver, WTI, BTC, ETH. 이 표시 이름을 API 심볼로 임의 변환하지 않는다.
- 0~5bps 구간 85%, 6~10bps 10%, 11~25bps 5%다. 기존 18bps는 마켓당 주 250 USDC를 여러 참여자가 나누는 구간에 해당한다. 한쪽 호가도 인정하며 무작위로 대략 분당 한 번 관측한다.
- 화요일~월요일 UTC 단위로 집계하고 주간 마감 후 48시간 안에 계정에 지급한다. 7일 시험이 두 정산 주간에 걸치면 마지막 주 지급을 기다린 뒤 결론 낸다. 미지급을 0 수익으로 단정하지 않는다.

공지에 없는 세부 배분·반올림·거리 경계 처리를 추측해 확정 수익으로 표시하지 않는다. 이번 주 목록은 다음 주에 자동 적용되지 않는다.

## 공개 호가 측정

공식 [깊이 조회](https://docs.ondoperps.xyz/api-reference/market-data/get-order-book-depth)에서 확인한 `/v1/perps/depth`, `market`, `depth=100`을 사용했다. Ondo 요청 간격은 1.1초 이상이다. 각 후보를 세 번 관측한 11~25bps 양쪽 합계와, 가정상 자기 호가 120 USD가 일주일 내내 같은 구간에 있었다면 받는 금액은 아래와 같다.

| 후보 | 경쟁 호가 USD 범위 | 정적 비례배분 시나리오 USDC/주 |
|---|---:|---:|
| BTC | 804,148~846,855 | 0.035~0.037 |
| ETH | 52,202~188,082 | 0.159~0.573 |
| META | 954,149~1,432,229 | 0.021~0.031 |
| COIN | 2,046,182~2,048,438 | 0.0146~0.0147 |
| MSTR | 1,254,732~1,417,747 | 0.021~0.024 |
| NVDA | 109,821~1,005,591 | 0.030~0.273 |
| TSLA | 206,353~1,104,066 | 0.027~0.145 |

식은 `250 * 120 / (경쟁 호가 USD + 120)`이며 공식 지급 예상액이 아니다. 짧은 시점 관측, 같은 구간 내 단순 비례, 100% 가동, 일정 경쟁 유동성을 가정한다. 스큐·호가 수정·체결·정지로 자기 호가가 바뀌며 정확한 지급 공식과 경계는 공개되지 않았다. 깊이가 잘리면 분모가 과소평가돼 더 낙관적일 수 있다. 표의 응답은 25bps까지 확인됐다. 한 시점의 ETH 실제 응답은 `tests/fixtures/reward-depth-eth.json`에 보존했다.

BTC+ETH는 가정상 주 0.19~0.61 USDC 수준이다. 이전 LIT·ENA 10분 시험의 종료 직후 자산 감소 1.310360 USDC는 수수료뿐 아니라 평가 손익도 포함하므로 주간으로 선형 환산하지 않는다. 다만 이 상태에서 수익성을 기대하며 확대할 근거는 없다. 4bps로 당기면 보상 구간은 커지지만 체결·역선택도 달라지므로 승인 없이 바꾸지 않는다.

## 헷지에서 확인한 것과 한계

LIT 4개 양쪽 진입·정리 시험과 메인 10분 시험은 완료됐다. 메인 시험의 Ondo maker 체결 이벤트 19건에 대해 Lighter 전송 18회가 모두 주문 최종 상태 `filled`와 정확한 포지션 반영으로 확인됐다. 소액 체결 하나는 누적 후 헷지돼 이벤트 수가 다르다. 미확정 0이며 결과 불명 시 시간만으로 재전송하지 않는 규칙을 유지한다.

BTC·ETH는 현재 양쪽 활성 마켓과 Lighter 최소 호가 금액 10 USD를 확인했다. 해당 두 자산으로 실제 체결·헷지를 시험한 것은 아니다. 기존 LIT·ENA 실측을 새 자산의 완료 증거로 대체하지 않는다. 주식의 기초시장 휴장 설정은 엔진에서 아직 강제되지 않으므로 주식 무인 운영을 제안하지 않는다. 데드맨 강제 종료 취소는 확인됐지만 ping 연장의 단독 증거는 아직 부족하다.

2026-10-29 23:08 UTC 조회: 열린 주문 양쪽 0, 미확정 0. Ondo LIT +40·ENA -453, Lighter LIT -40·ENA +453이 남아 있다. 자산은 250.875284 / 250.638071 USDC였고 이후 평가액은 변한다. 이 포지션은 정리 없이 새 마켓 설정으로 전환하면 관리 대상에서 빠진다. 후보 설정의 live 시작은 이처럼 설정 밖 포지션이 있으면 취소·레버리지 변경 전에 차단된다. 마이그레이션 전에 별도 승인된 reduce-only 정리와 양쪽 최종 0 확인이 필요하다.

## 구현된 관측과 실주문 재개 조건

`python -m olbot.reward_probe --duration 604800 --interval 300 --output outputs/reward-week.jsonl`은 5분마다 공개 호가만 기록한다. 주간 정책 만료 뒤에는 보상 시나리오를 중단하고 자격 미확인으로 표시한다. 전송 실패는 유형만 기록하고 다음 관측으로 넘어간다. PC·네트워크 중단 시 누락이 생기며 기록의 최신 시각을 확인한다. 재부팅 후 임의로 실주문을 재시작하지 않는다. 실주문 봇과 동시 실행하면 서로 다른 버킷으로 IP 요청 예산을 공유하지 못하므로 **관측 프로세스를 먼저 종료**한다.

`config.reward-week.example.yaml`은 BTC·ETH 각 방향 60 USD, 기존 노출·손실 기준을 유지한 **dry_run 후보**다. 정책은 `docs/rewards-2026-10-27.json`에 확인된 24시간 암호화폐 두 개만 허용했다. 정책 밖 마켓·유효기간 밖 live는 시작 전 차단한다. 실행 중 만료는 새 호가를 막고 기존 호가를 내리며 독립 헷지 루프는 계속한다. REST 대기 사이 만료도 생성 직전에 재검사한다. 자동 목록 갱신이나 자동 마켓 변경은 없다.

실주문 재개에는 기존 LIT·ENA 정리, BTC·ETH 마켓 변경, 기간·금액·종료 처리 범위를 한 번에 정한 사용자 승인이 필요하다. 새 주문 최소 단위·포지션/주문 0·미확정 없음·인증을 다시 확인하고 10분 새 자산 시험부터 확인한다. 데드맨 연장 증거가 부족하면 그대로 보고하고 무인 운영으로 확대하지 않는다. 기존 손실 25 USD 기준은 프로세스 시작 대비이며 재시작하면 초기화되므로, 1주 누적 손실 예산을 영속화하기 전 자동 재시작하지 않는다. 정지는 최대 손실 보장이나 포지션 자동 청산을 뜻하지 않는다.

리포트는 전송과 최종 기록을 분리하며 `final:filled`를 거절로 세지 않는다. 보상 정규화는 같은 완결 주간의 호가 노출만 사용한다. 샘플 노출을 실제 open 시간이나 리워드 확정 자격이라고 표시하지 않는다. 실제 지급액, 수수료·헷지/펀딩·평가 손익, 관측/가동 시간을 나눠 판단한다. 공개 관측 일주일만으로 순수익을 입증했다고 주장하지 않는다.
