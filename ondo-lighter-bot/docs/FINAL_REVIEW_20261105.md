## 펀딩과 META 재검토

10월28일04UTC~11월4일03UTC168시간의 고정200USD 명목 참고 계산에서 시작 전 신호로 방향을 고정한 결과는 ETH -0.13286USD, META +0.30096USD다. 이 수치는 실제 같은 기초수량 보유 손익도, 현재 펀딩의 미래 보장도 아니다. META의 양수도 조사한8개 표본 중의 값이며 일반적인 최대 수익 한도가 아니다.

이전 왕복 비용0.22~0.38USD는 Premium 가정이었다. 현재 Standard 일반 주문 수수료0을 반영해 같은 과거 공개 호가 스냅샷에서 Lighter 수수료 항목만 제거하면 META 왕복 비용 참고값은 약0.12409USD다. 따라서 ‘펀딩은 항상 왕복 비용보다 작다’고 단정할 수는 없다. 다만 두 열의 시점이 다르고 Standard 추가 지연·미래 가격차·실제 동일 수량 현금흐름을 포함하지 않아0.30096−0.12409를 실제 주간 순이익으로 부르지 않는다. 규모상500USD로 주2USD 순이익이라는 목표를 지지하지도 못한다.

Standard 공식 조건: https://docs.lighter.xyz/trading/trading-fees (일반 maker/taker0, taker300ms).

호가 체결로 재고 방향이 바뀌는 봇이 항상 펀딩을 받는 것은 아니다. 별도200USD 쌍의 펀딩 수입을 같은500USD 자본의 호가 전략에 공짜로 추가하지 않는다. META의 실행 관측은 중단과 정규장 표본 부족이 있어 원래 보고서의 전체 순이익은 산출 불가다. ETH의 비용 배율을 그대로 옮긴 ‘META 주-3USD’ 역시 검증된 실손익이 아니다. 확실한 수익이 증명되진 않았지만 추가 실험을 중단할 근거는 충분하다.

활동 보상은 ETH 자격/금액 미확인, 포인트는 현금 환산 가치 미확인이다. 이를 임의의 확정 수익으로 더하지 않는다. Jumper 경유 보상도 현재 직접 API 봇의 자격이 확인되지 않아 넣지 않는다.
