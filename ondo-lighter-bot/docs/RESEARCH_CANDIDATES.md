# 기본 검토 후보: BTC·ETH·META

2026-11-01 사용자가 META를 기본 후보에 추가했다. 아래는 **공개 관측·후속 검증 후보 목록**이며 실주문 허용 목록이나 실행 중인 마켓 목록이 아니다.

| 후보 | 조합 | 현재 근거 | 다음 검증 |
|---|---|---|---|
| BTC | Ondo maker / Lighter 반대 IOC | 기존 공개 비교·확정 펀딩 이력 | 기존 관측 공백·가상 상태를 보존한 복구 검토 |
| ETH | Ondo maker / Lighter 반대 IOC | 기존 공개 비교·확정 펀딩 이력 | 같은 기준으로 비용 후 순이익 비교 |
| META | Ondo maker / Lighter 반대 IOC | 11월1일 일요일 공개 깊이2개 표본 | 정규장·야간·주말별 보상 점유율과 체결·헷지·펀딩·청산 비용 |

TSLA·NVDA는 예비 검토 후보로 남긴다. META 추가만으로 이 둘을 기본 후보나 실주문 대상으로 바꾸지 않는다. pre-IPO는 별도의 계약·정산 위험 연구 대상이다.

## META 숫자의 의미

이번 표본에서 Ondo META 호가를5bps 안쪽, 매수·매도 각각 최대60 USD(합계 최대120 USD)로 놓았다고 가정했다. 최소 단위로 내린 실제 모형 호가 합계는 약110.55 USD였다. 정적 비례배분의 비용 전 주간 환산은 약8.6~13.2 USDC다.

- 전체 자본500 USD를 기준으로 후보를 비교한다. 60 USD를 입금해13 USDC를 받는다는 계산이 아니다.
- 현재 경쟁 깊이와 호가 조건이7일 유지되는 가정이다. 실제 지급액·순이익·수익률을 검증한 결과가 아니다.
- 수수료·헷지·펀딩·거래소 간 가격차 변화·정리 비용을 차감해야 한다. META와 BTC/ETH의 서로 다른 길이 관측을 같은 증거로 취급하지 않는다.
- 이번 공식 보상 주간은11월3일09:00 KST에 끝난다. 다음 주 대상·풀·산식을 확인하기 전에는 이 가정을 연장하지 않는다. [공식 공지](https://app.ondoperps.xyz/announcements/usdc-rewards-upgrade).

## 측정 기준

META도5/10/18bps를 비교 후보로 두되 우선 가설은5bps다. 거리·마켓 선택에 사용한 초기2개 표본은 탐색 자료로 표시하고, 새 관측은 실제 새 시작 시각부터 기록한다. BTC/ETH의 기존6행·12개 모형에 META를 소급 추가하지 않는다. 기존 마감은11월6일20:43 KST다.

새 관측에서는 America/New_York 시간대 기준 정규장·정규장 밖 거래 가능 시간·휴장/주말을 구분한다. DST·휴일·거래 중단을 반영하고, 외부 주가와 내부 가격 발견의 전환 구간도 표시한다. 이전 자료에 없던 시세나 체결을 만들어 채우지 않는다.

같은 수량으로 헷지할 수 있는지, 두 거래소의 가격·수량 최소 단위와 Lighter 최소 주문 조건, 공개 깊이, 실제 수신 지연을 확인한다. 가상 부분 체결·최소300ms 헷지 지연·양쪽 실제 지급 시각의 펀딩을 기존 기준과 같이 계산한다. 순수익 판단 기준은 전체 자본500 USD에 비용 후 주2 USDC다. 여러 대안을 합산해 기준을 통과시키지 않는다.

후보3개를 동시에 운영하거나 자본·전체 재고 한도를 늘리는 설정은 만들지 않는다. 향후 어떤 마켓 조합을 동시 운영할지는 동일한 자본과 재고 한도 안에서 별도 평가한다. Ondo의 REST 초당1회 예산을 유지한다.

## 실행 상태와 승인 범위

현재 실제 주문은 정지 상태다. 기존 BTC·ETH 공개 수집기도10월31일23:20경부터 중단됐고,11월1일 프로세스 부재를 확인했다. 펀딩 마지막 갱신은23:05경이다. 기록을 보존하고 자동 재시작하지 않는다. 가상 체결 이력이 있어 단순 `--resume-flat` 재사용은 불가하다.

이번 변경은 후보 등록과 측정 기준 정리다. 실제 `config.yaml`, `.env`, 거래 `data/`, 기존 BTC/ETH 주간 정책·수집 프로토콜을 바꾸지 않는다. 새 수집 실행·기존 관측 복구를 완료했다고 표시하지 않는다. 실주문 전에는 해당 주 보상 자격·주식 휴장 제어·상태 대사·수량·금액·종료 범위를 확인하고 사용자 승인을 받는다.
