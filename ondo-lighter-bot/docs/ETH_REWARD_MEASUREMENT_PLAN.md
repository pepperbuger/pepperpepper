# ETH 실제 호가 보상 측정안 — 구체 범위 승인 대기

2026-11-04 사용자가 "실주문 안 해도 리워드가 쌓이는지 알 수 있나, 모른다면 실주문도 넣자"고 요청했다. 모의관측은 실제 보상을 적립하지 않는다. 거래소에 실제로 남아 있는 지정가 호가는 체결되지 않아도 유동성 보상 대상이 될 수 있다.

11월3일 BTC10분 시험도실주문이었지만보상기간이짧아반올림/최소지급/분배식영향을배제할수없다. 현재보상적립/지급여부를확정하지못했다. 새측정안은소액장시간관측이며수익이입증된운영확대가아니다.

## 공식 화면에서 다시 확인한 것

11월4일20:43 KST경 [Rewards](https://app.ondoperps.xyz/rewards)를로그인없이직접확인했다. Week2 총250,000/유동성112,500USDC,20개마켓링크·25bps·한쪽호가자격·5bps안쪽85%를표시한다. 현재UI가직접연결한목록에는ETH가있다. 지급내역의2주차는 **12 Nov2026 / 대기 중**이다. 현재주간끝은11월10일09KST이고당일즉시지급확인을보장하지않는다.

연결된글의날짜/마켓별5,000은지난주그대로이므로이번주배분액으로확정하지않는다. 새ETH전용 `scope: eligibility_only` 정책은자격/유효기간검사만허용하고금액모형loader는거부한다. 개인수령액은로그인전대시값에서추론하지않는다.

자산 기준 정지는 외부입금/출금/리워드지급의영향을받을수있다. 특히11월5일이전주보상지급이겹칠수있어원시자산변화를무조건이번시험의순수거래비용으로부르지않는다. 지급/이체내역을대조하지못하면비용확정값을산출불가로남긴다. 이번주수령총액도BTC시험분/거래량보상등과구분해야한다.

처음ETH로한마켓부터측정한다. META는비교후보로유지하며이안에META실주문은포함하지않는다. 입출금·이체·키등록·등급변경·다른마켓정리·기존공개수집기재개도포함하지않는다.

## 실행·중단·기록

별도 `config.measure-eth.example.yaml`을사용하고기존config.yaml/.env/운영DB·안전기록을교체하지않는다. 메인엔진의동일live경로와기존운영DB를사용한다. 새 `eth_cleanup`은ETH만허용하며새저널과명시승인을요구한다. BTC/LIT/ENA의소진된승인을재사용하지않는다.

PC와인터넷을켜둬야24시간측정할수있다. PC/프로세스가꺼지면데드맨이호가를취소하지만헷지된포지션은남을수있다. 자동재시작하지않으며재가동후먼저계정/미확정을확인한다. 정상종료나위험정지는호가취소후승인범위안에서확정잔량만정리한다. task폴더출력의`STOP`파일은새호가를멈추고동일종료절차로넘기는운영중단신호다. 실행기는오류를즉시파일로기록하고채팅알림은별도5분점검에서발견시전달한다. PC가꺼지거나앱이실행되지않으면점검도중단될수있다.

준비파일은 `outputs/eth-reward-prep-20261104/`, 실제실행시새기록은 `outputs/eth-reward-measure-20261104/`다. 실행기에는구체범위승인파일·설정해시·한번만생성하는authority저널검사가있다. 승인전에는실주문을시작하지않는다.

24시간뒤호가USD-시간·5bps구간비중·체결·헷지·불일치·실제자산변화를보고한다. 지급액은주간정산후따로확인하고실제수령종류/주간을맞춰보상에서비용을뺀다. 보상이표시되지않는것을즉시미적립으로판정하지않고최소지급·반올림·자격을확인한다. 이측정만으로월/연수익률을확정하지않는다.
