# Jumper Perps — 보상 조건 검증 후보

2026-11-04 사용자 요청으로 추가 후보에 등록했다. 현재는 문서·공개 수치 비교 단계이며 실제 주문·계정 연결·builder 등록·장기 관측을 시작한 상태가 아니다. 기존48개 가상 모형이나500USD 자본에 Jumper 수익을 추가하지 않는다.

## 확인된 것과 미확인

- [DefiLlama Jumper Perps](https://defillama.com/protocol/jumper-perps)의11월4일 조회값은 최근7일 거래량약34.46M USD다. 집계 설명에는 Hyperliquid와Lighter 및Robinhood Chain의builder/partner 경로가 나온다. Ondo 경로 보상 대상 거래량과 동일한 분모라는 근거가 없다. 최근7일과 캠페인의 고정 주간도 다를 수 있다.
- 사용자 제공 글의 수수료 maker0.07%/taker0.10%, 거래량 비례 달러 분배,45M 손익분기점은 **미검증 주장**이다. 글에는 계산표와 확정 현금 풀 금액이 없었다. 포인트는 달러로 환산하지 않는다.
- 공식 `https://perps.jumper.xyz/`와공식X는자동조회에서403을반환해현행캠페인분배조건을직접확인하지못했다. 외부포스트의"최대57,000USDC"를전액거래량풀·보장지급으로쓰지않는다.
- 현재 봇의 Ondo 직접 API 주문이 Jumper 경유 보상까지 인정된다는 근거가 없다. 동일 계정 인식과 builder/partner 거래 귀속, API 주문의 자격은 별도 확인 대상이다.
- 실제 Lighter 계정은 Premium이다. 현재 무스테이킹 taker0.0280% 비용을 헷지에 반영한다. Standard/fee0 대안과 혼동하지 않는다.

## 계산 방식

현금 풀이 전액 같은 단위의 인정 거래량에 비례한다는 조건에서만:

`예상 현금 보상 = 확정 현금 풀 × 내 인정 거래량 / 최종 전체 인정 거래량`

`순손익 = 위 보상 − Jumper 경유 총수수료 − 반대 헷지 수수료 − 스프레드/괴리/깊이/지연 비용 ± 펀딩 − 종료 비용`

수수료와 보상은 같은 편도 체결 거래량 단위로 맞춘다. 진입·정리 양쪽이 집계되면 수수료도 양쪽을 센다. 비용이 이미 양 거래소 현금흐름에 들어 있으면 다시 차감하지 않는다. 자기 거래량이 경쟁 거래량에 비해 크면 분모에도 본인 거래량을 포함한다.

아래는 **확정 보상 예측이 아닌 예시**다. 현금 풀50,000USD·내 인정 거래량10,000USD·글의 maker7bps/taker10bps·동일 거래량의 Lighter 헷지2.8bps·나머지 비용2bps를 가정한다. 미래 펀딩과 돌발 체결 손실은 별도다.

| 최종 인정 주간 거래량 | 보상 가정(USD) | maker+헷지 순손익 가정 | taker+헷지 순손익 가정 |
|---|---:|---:|---:|
| 25M | 20.00 | +8.20 | +5.20 |
| 35M | 14.29 | +2.49 | -0.51 |
| 45M | 11.11 | -0.69 | -3.69 |

이 가정의 분기점은 maker약42.37M·taker약33.78M이다.45M을 모든 계정/체결 방식에 적용할 수 없다.500USD 원금의 주간 수익률 표도 아니다. 늦게 진입해도 마감까지 남은 경쟁 거래량과 본인 거래량이 최종 분모를 바꾼다.

## 검증을 통과해야 할 항목

1. 유효 주간·정확한 현금 풀·분배 공식·상한/자격/포인트 가중을 공식 문서나 실제 화면으로 확인한다.
2. 보상 대상인 Jumper-Ondo 경로의 최종 인정 거래량을 별도로 확보한다. builder 소유자용 통계 API가 있다는 사실만으로 우리 계정에서 전체 경로 거래량을 볼 수 있다고 가정하지 않는다.
3. 경유 수수료가 Ondo 거래 수수료를 포함하는지와 builder 추가분을 구분한다. maker 유지·부분 체결·헷지·정리를 모두 포함해 같은 체결금액 단위로 비교한다.
4. 현재 전략을 경유시켰을 때의 추가 현금 보상이 추가 수수료·실행 비용을 넘는지 판단한다. 거래량부터 늘리거나 기존 거래량을 소급 귀속시키지 않는다.

현재 판단: **조건 확인 후 비교할 후보 유지, 예상 순이익은 미확정**. 실주문이나 계정 등급/키 변경은 새 범위 승인 전 실행하지 않는다.
