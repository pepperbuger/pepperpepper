# Ondo 보상·펀딩과 Jumper 후보 검토 — 2026-11-04

기존 공개 관측을 재시작하지 않고 공개GET으로8개 마켓을 한 번 조회했다. 키·계정 조회·서명·주문은 사용하지 않았다. 기존API공유잠금과1.1초 간격을 사용했고 `.env`, 기존config.yaml, 거래data, 과거 관측/펀딩 원본은 변경하지 않았다.

## 판단

- **Jumper는추가정책검증후보**다. [별도후보문서](JUMPER_CANDIDATE.md)에 분모·수수료·자격·손익분기 조건을 정리했다. 확정 현금 풀과 Ondo 경로 거래량이 미확인이라 현재 순이익을 제시할 수 없다.
- **펀딩만으로500USD 자본 주2USD 목표를 채울 근거는 약하다.** 고정200USD 명목 참고 계산에서 양수였던 마켓도 최근7일 펀딩이 수십센트 수준이다. 실제Premium 수수료·가격차 변화·진입/정리 비용이 중요하다.
- **호가 보상 쪽은 현재 마켓별 풀 확인이 우선**이다. 깊이 한 장으로는 미래 경쟁·체결 손실·공식 지급액을 알 수 없다. 실제 수령액은 여전히 미확인이다.

## 7일 확정 펀딩 이력

정산 시각 창은 **2026-10-28 04:00~2026-11-04 03:00 UTC**(한국10월28일13시~11월4일12시)168회다. 각 마켓 양 거래소168시간이 모두 있다. Ondo는시간당소수비율, Lighter는방향을적용한percent를100으로나눴다. 차이는 `Ondo−Lighter`다.

## 호가 보상 검토

11월3일 직접 읽은 [공식 Rewards UI](https://app.ondoperps.xyz/rewards)는Week2 총250,000/유동성112,500USDC와20개 대상 링크·25bps·한쪽자격·5bps 안쪽85%를 보여줬다.11월4일 공개 공지 목록과 연결된 [업그레이드 글](https://app.ondoperps.xyz/announcements/usdc-rewards-upgrade)을 다시 읽었지만 해당 글의updatedAt은10월27일이고 금액/유효 주간도지난주다. 새 마켓별 배분을 확인하지 못했다.112,500/20=5,625나 지난주5,000을 이번 주 확정 풀로 쓰지 않는다. 기존 공개 모형 정책 파일도 갱신하지 않았다.

## 실제 수령액

공식 [지급 표시 공지](https://app.ondoperps.xyz/announcements/reward-deposits-now-show-as-transfers)는보상입금이Portfolio → Account Activity → Transfers에표시된다고명시한다. 공개OpenAPI에서는전체Perps보상송금이력을보장하는GET경로를찾지못했다. Spot전용transfers를Perps보상지급총액으로대체하지않았다. 로그인화면을현재읽지못한상태이므로수령액을0으로기록하지않는다.11월3일BTC시험분과그전거래분의보상주간도구분해야한다.

## 수집/파서 수정과 한계

실제 응답에 `2026-11-02T15:03:54.896752592Z` 정산이8개마켓모두있었다. [공식 펀딩 문서](https://docs.ondoperps.xyz/funding-rates)는정각후첫tick에적용한다고설명하며60초이내를보장하지않는다. 기존파서는1분초과행때문에응답전체를거부했다.

Ondo에만첫tick지연을허용하고실제 `settled_ts`는유지했다. 같은UTC시간의중복정산·비정상단위·비유한값은계속거부하며Lighter검증은그대로다. 지연tick당시의재고로펀딩을계산하는회귀도추가했다. 이전코드에서핵심재현2개가실패했고수정후전체356개가통과했다.

task폴더 `outputs/reward-funding-review-20261104/`에조회시각·공식문서·원본·계산JSON을보존했다. 초기파서거부결과도별도파일로남겼다. 원래1주관측의가격/체결공백이나first_seen은채우거나수정하지않았다. 이별도7일비율조회는기존실행관측전체순이익을복원하지않는다. 원래11월6일마감·공개작업자정지·실주문정지상태를유지한다.
